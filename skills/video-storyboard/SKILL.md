# 通用短视频分镜 / 脚本 / 提示词生成

一条可交付的视频，无论哪个行业，都先想清楚三件事：**给谁看（人群）→ 为什么停（钩子）→ 看完做什么（行动）**。本 skill 把这三件事拆成可执行的分镜和提示词，直接粘到任意视频生成模型即可跑。

> 行业不限：植发/医美、电商带货、知识科普、餐饮、教育、旅行、科技工具都适用。下面的模板里的「[]」请你按实际主题填，不要套死。

## 三步前置（生成前必问，缺则用默认）

1. **时长+画幅**：默认 5-8 秒，9:16 竖版（小红书/抖音）。若用户说横屏/更长，记下。
2. **风格基调**：写实/电影感/简约扁平/手绘/慢动作/快剪，默认「真实自然、暖色、清晰」。
3. **核心信息**：一句话说清「这条视频要传达的唯一一件事」，没有就看用户给的主题。

## 输出公式（四种形态按需选）

### A. 分镜提示词（一段式，给视频模型）
```
【风格】[风格]，[时长]秒，[画幅]比例，[氛围]
【时间轴】
0-[x]秒：[景别]+[画面内容]+[动作/运动]+[特效/转场]
[x]-[y]秒：[景别]+[画面内容]+[动作/运动]+[特效/转场]
【声音】[配乐风格]+[音效]+[是否有人声/对白]
【参考】@图片1 [用途]，@视频1 [用途]
```
- 写「意图」别写「细节」：不需要把每个动作描述到毫秒，给模型发挥空间更好。
- 首帧最好给明确主体，尾帧给出结果/结论，形成闭环。

### B. 口播脚本（真人出镜/配音）
```
【开场钩子】(1-2句，抛出痛点/反常识/数字，让人停)
【主体】(3-4个要点，每点：观点+一句支撑+一句人话)
【结尾行动】(引导动作：评论/私信/关注/下单)
【语气】[亲切/专业/幽默] ，【时长】建议 [x] 秒
```

### C. B-roll 清单（给剪辑/多镜头）
按「环境空镜 → 动作特写 → 结果展示 → 情绪卡点」给 6-8 个镜头，每个标注画面+运镜+时长。

### D. 封面（如需要，交给 cover 类 skill）
输出一条 3:4 竖版封面提示词，突出一个关键词。

## 合规底线（医疗/美食/功效类尤其注意）
- 不承诺疗效/结果/保证。医疗类用「有助于、多数反馈」等客观表述。
- 不夸大、不虚假对比、不引导站外私下交易。
- 真人出镜需获授权，涉及患者/面部需打码或特写授权。
- 不接自动发布（本 skill 只做创作，发布走手动）。

## 质检（输出前自检清单）
- [ ] 前 3 秒有没有钩子（能不能让人停）
- [ ] 是否只说清「一件事」
- [ ] 结尾有没有明确的下一步动作
- [ ] 有没有踩合规红线
- [ ] 时长/画幅是否符合目标平台

## 示例（非植发，通用演示）
> 主题：一家咖啡店新品。→ 选 A 一段式：
> 【风格】写实生活感，暖色调，7秒，9:16
> 【时间轴】0-2s 特写+咖啡杯拉花成型（慢放）；2-5s 中景+顾客手拿咖啡嘴角上扬（稳定推镜）；5-7s 全景+店面招牌与新品特写卡（硬切，画面淡出）。
> 【声音】轻快爵士+环境杯碟声，无对白
> 【参考】@图片1 咖啡拉花特写
